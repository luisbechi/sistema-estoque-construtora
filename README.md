# 🏗️ Sistema de Estoque para Construtora

Este é o meu primeiro projeto completo de desenvolvimento, criado com o objetivo de colocar em prática meus estudos em **Análise e Desenvolvimento de Sistemas** e, ao mesmo tempo, desenvolver uma solução para uma necessidade real de uma empresa.

## 📌 Sobre o projeto

Atualmente estou trabalhando na montagem e configuração de um **servidor local do zero para uma empresa do setor de construção**, envolvendo desde a preparação do hardware até a configuração do ambiente que será utilizado para armazenamento e compartilhamento de arquivos.

Durante o desenvolvimento desse projeto surgiu a ideia de ir além da infraestrutura e criar também um **sistema próprio para controle de estoque da empresa**.

O objetivo é integrar futuramente o sistema ao servidor e apresentar uma solução completa para a empresa.

Este projeto também faz parte do meu processo de aprendizado, permitindo que eu desenvolva conhecimentos em **programação, banco de dados, APIs, servidores, Linux, redes e infraestrutura** através de uma aplicação real.

---

## 🎯 Objetivo

O sistema será simples, intuitivo e funcional.

A ideia é permitir que funcionários, responsáveis e administradores consigam acessar o estoque através do navegador, utilizando computadores, tablets ou celulares conectados ao sistema.

Entre as funcionalidades planejadas estão:

- Cadastro de produtos, materiais e ferramentas
- Organização por categorias
- Registro de entrada e saída de estoque
- Controle de materiais destinados às obras
- Histórico de movimentações
- Controle de usuários e níveis de acesso
- Controle de estoque mínimo
- Alertas de estoque baixo
- Dashboard com informações do estoque
- Acesso através de computadores e dispositivos móveis

No futuro, pretendo implementar também identificação de ferramentas através de **QR Code**, facilitando o registro de retirada e devolução de equipamentos.

---

## 🖥️ Infraestrutura

Além do desenvolvimento do sistema, o projeto envolve a criação da infraestrutura onde ele poderá ser utilizado.

A proposta é utilizar um servidor local na empresa para centralizar serviços e arquivos, permitindo que diferentes computadores e dispositivos da rede tenham acesso aos recursos necessários.

Também pretendo estudar e implementar estratégias de **backup em nuvem**, aumentando a segurança dos dados da empresa.

Dessa forma, o projeto envolve tanto **desenvolvimento de software** quanto **infraestrutura de TI**.

## 🗄️ Banco de dados

O banco de dados está sendo desenvolvido em **MySQL**.

Atualmente a estrutura inicial contempla:

- Usuários
- Produtos
- Categorias
- Obras
- Movimentações de estoque

O estoque é calculado através do histórico de movimentações, permitindo registrar entradas, saídas e ajustes sem perder o histórico das operações.
